A string is a data type that represents a sequence of characters. Characters include letters (a-z, A-Z), digits (0-9), spaces, punctuation marks, and other symbols. Strings are one of the most fundamental data types in programming, used to represent text and communicate with users.

Strings as Collections of Characters

A string can be thought of as an ordered list of characters. For example, the string "hello" is a sequence of five characters: h, e, l, l, o. Each character in the string occupies a position, which is often referred to using a numeric index.

Example indices in the string "hello":


Position:  0  1  2  3  4
Character: h  e  l  l  o

Notice that most programming languages use 0-based indexing, where the first character is at position 0. A minority of programming languages use 1-based indexing, where the first character is at position 1.
